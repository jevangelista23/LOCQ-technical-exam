# Playwright TodoMVC Automation (TypeScript)

## 📦 Installation
```
npm install
```

## ▶️ Run all tests
```
npx playwright test
```

## 🪟 Run in UI mode
```
npx playwright test --ui
```

## 📄 Test Scenarios Automated
1. Create a Todo
2. Edit a Todo
3. Delete a Todo
4. Complete a Todo
5. Clear Completed Todo
